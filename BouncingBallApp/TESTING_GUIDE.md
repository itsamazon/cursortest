# 🧪 Testing Guide for Bouncing Ball App

## Quick Start for Testers

### Step 1: Get the App Running
1. **On your computer**: Open terminal/command prompt
2. **Navigate to the app folder**: `cd BouncingBallApp`
3. **Install dependencies**: `npm install`
4. **Start the app**: `npx expo start`

### Step 2: Test on Your Phone
1. **Install Expo Go** on your phone:
   - **iPhone**: App Store → Search "Expo Go"
   - **Android**: Google Play → Search "Expo Go"

2. **Scan the QR code** that appears in your terminal:
   - **iPhone**: Use the Camera app
   - **Android**: Use the Expo Go app

3. **The app will load** on your phone automatically

## 🎯 What to Test

### Basic Functionality
- [ ] **App loads** without crashing
- [ ] **Start button** makes the ball move
- [ ] **Pause button** stops the ball
- [ ] **Settings button** opens customization panel
- [ ] **Ball bounces** off walls properly

### User Experience
- [ ] **Ball moves smoothly** (no jerky motion)
- [ ] **Speed feels calming** (not too fast)
- [ ] **Sounds are pleasant** (if you hear them)
- [ ] **Buttons are easy to tap**
- [ ] **App looks good** on your screen
- [ ] **Settings panel opens/closes** properly
- [ ] **Color changes work** (ball and trail change color)
- [ ] **Speed changes work** (ball moves faster/slower)
- [ ] **Sound toggle works** in settings

### Technical Issues
- [ ] **No error messages** in the terminal
- [ ] **App doesn't crash** when switching between start/pause
- [ ] **Sound works** (if you have a bounce.mp3 file)
- [ ] **Performance is smooth** (no lag)

## 🆘 If Something Goes Wrong

### Common Problems:
1. **"Expo command not found"**
   - Try: `npx expo start` instead

2. **"Port already in use"**
   - Press 'y' when asked to use different port

3. **App won't load on phone**
   - Make sure phone and computer are on same WiFi
   - Try restarting the Expo Go app

4. **No sound**
   - Check phone volume
   - Make sure sound is enabled in app

### Get Help:
- Check the terminal for error messages
- Try restarting: `npx expo start --clear`
- Ask the developer for help!
